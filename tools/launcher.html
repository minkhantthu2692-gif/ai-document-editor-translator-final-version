Run the app locally, keep the repo clean, and know which gate step is next.

Setup checklist

Tick each step as you go. “Re-check” pings the dev server; your ticks are remembered in this browser.

  1. 1. Node.js 18 or newer …
    Any Node ≥ 18 works (the app uses ES modules and WebCrypto).
    node -v
  2. 2. Install dependencies
    Run once after cloning (or whenever package.json changes).
    npm install
  3. 3. Create .env
    Copies .env.example → .env (git-ignored). Optional keys only.
    cp .env.example .env
  4. 4. Start the dev server …
    Serves http://localhost:5173 — “Re-check” probes it for you.
    npm run dev
  5. 5. Tests + lint + format
    The full gate: typecheck, ESLint, Prettier, Vitest.
    npx tsc --noEmit && npx eslint . && npx prettier --check .
    npx vitest run
  6. 6. Production build
    Outputs dist/ — also what the GitHub Pages workflow ships.
    npm run build
  7. 7. No secrets in git
    .env, node_modules/ and dist/ must stay untracked.
    git status --porcelain
  8. 8. Push to GitHub
    The guided script verifies .gitignore, prompts for a message, then pushes.
    tools/push-to-github.sh
